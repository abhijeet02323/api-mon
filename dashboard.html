Add API test case

Methods: GET, HEAD, POST, PUT, PATCH, DELETE. Write methods require confirmation when saved and again when run. Scheduled writes need a separate opt-in. Use env:SENTINEL_SECRET_NAME for sensitive headers and {{env:SENTINEL_SECRET_NAME}} in bodies. Secret values come from app environment variables and are not stored; body templates are stored in SQLite, so do not type literal credentials. Chained steps can extract JSON values for later URLs, headers, or bodies with {{variable}}.

Assertions use dot paths and array indexes. Operators: equals, not_equals, contains, gt, gte, lt, lte, exists, not_exists. Response bodies are capped at 256 KiB and never stored.
